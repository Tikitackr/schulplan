# schulplan

Eine Seite, die einen Stundenplan anzeigt. Sie enthält selbst keine Daten.

Die Adresse der Datenquelle steht hinter dem Rautezeichen im Link und wird von
Browsern nicht an den Server geschickt. Ohne diesen Teil zeigt die Seite
nichts an.

Gebaut für den privaten Gebrauch einer Familie.

## Prüfen

npm test
